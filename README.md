# SafeSpace chatbot

A simple personal-safety support chatbot made with HTML, CSS, and JavaScript.

## Run locally

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Open a terminal in this project folder.
3. Run:

   ```sh
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000).
5. Press `Ctrl+C` in the terminal to stop the server.

To use a different port, set `PORT` before starting the server. For example, in PowerShell:

```powershell
$env:PORT=3001
npm start
```

The chatbot runs entirely in your browser and does not save or send messages.
